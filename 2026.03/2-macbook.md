# macbook

> 2026年8月20日注，macbook的窗口管理模式和Windows不同，使用macbook的时候应该避免频繁拖动窗口，反而macbook 切换 workspace非常丝滑。

我花了三千块在咸鱼上买了一个 2020 年的 macbook air m1 16 + 512. 用了一段时间之后我理清了 macbook 的责任边界和定位，它在轻薄本上做到了极致，断然抛弃了所有沉重工作场景。

1. 作为一个开发者, 我通过异地组网工具连接 macbook 和 homeserver.
2. macbook 续航非常长, 一小时耗电不到10%.
3. 在家接用拓展坞接显示器和键鼠, 在外用手机的 typec 充电器就可以充电.
4. mac的操作系统方面有两点:
	1. 快捷键习惯方面, 从 windows 切换到 macos 对我来说没有难度, 但是频繁来回切换很难受, 所以我放弃了在 windows 进行工作, 只用来娱乐.
	2. macos 系统的界面设计我很喜欢, 我觉得更胜 windows. 但是也不是没有缺点, macos 的窗口管理没有 windows 的 win + tab 和 alt + tab 两层切换方便.

本文下面主要说明我把 macbook 当做主力之后, 遇到的一些克服的困难的经验

## 漏电

我的 macbook 在充电的时候漏电非常严重, 被电到会非常疼, 我开箱一小时内就注意到了这个问题.

而且我发现这个充电器就是漏电的, 如果我摸充电线 Type-C 接口的金属部分也会被电的很疼.

解决方法有三个:
1. 充电的时候不碰它, 要么等充好了再用, 要么接键鼠显示器用.
2. 双脚离地, 不会被电.
3. 使用支持 PD 协议(用 Type-C 充电的协议一般是 PD 协议, PD 是 Power Delivery 的意思) 的拓展坞充电, 机身和充电器隔了一个拓展坞就不会漏电了.

> 2026年8月20日注, 我现在用120w小米充电器给它充电，充了几个月反正没啥事。

## 外接键鼠和显示器

外接键鼠显示器的工作效率会完全上升一个维度, 我不觉得这个触摸板能比鼠标的效率还高, 触摸板只有两个功能: A. 控制鼠标指针, B. 管理窗口和多桌面. 

- 功能 A 方面, 触摸板的体验完全比不上鼠标, 但是 macbook 的金属触摸板确实比部分 windows 的塑料触摸板手感要好. 
- 功能 B 方面, 触摸板的效率只能和快捷键的效率平分秋色, 而快捷键还能实现更多的功能.
- 因此我并不是特别喜欢 macbook 的触摸板, 因为我一直都不喜欢任何触摸板.

外接设备的时候通常要边充边用, 这样还能够保护 macbook 的电池寿命.

我特地买了一个新的支持充电和视频传输的拓展坞, 否则我的 macbook 只有两个 c 口, 没有办法接这么多东西. 另外 macbook 相关的周边物品也都要比一般电子产品的都要贵很多.

## betterdisplay 控制多显示器

问题: 我的 macbook 无法关闭内置显示器, 只能把它亮度调到最低, 这会导致我的鼠标指针有时候会被判定为进入了另一个屏幕的区域, 或者 alt+tab 切换窗口的提示框会出现在内置显示器中.

betterdisplay 可以直接控制显示器开关, 以及最重要的是控制在第二屏幕上的字体渲染.

## linearmouse 鼠标

macbook的触摸板和鼠标底层用的是相同的信号, 这就导致虽然在系统设置可以分别设置鼠标和触摸板的自然滚动, 但实际上改了其中一个,另一个也会更改.

linearmouse 也不能区分触摸板和鼠标, 但是它可以针对每个不同的设备修改滚动方向和滚动模式,如果把滚动模式改成按行, 就和 Windows 的手感一模一样.  

另外还可以设置一些全局鼠标手势, 但我不太用的习惯.

## karabiner 改快捷键

我一开始尝试适应 macbook 的快捷键, 我成功了, 并没有想象中的困难. 困难的是在 macbook 和 windows 来回切换, 所以我尝试通过 karabiner 为 mac 设置 windows 风格的快捷键.


karabiner 可以为不同硬件设置按键映射规则, 并且还支持非常复杂的规律, 这是我当时设置的规则, 大部分都可以通过 [这个规则集](https://ke-complex-modifications.pqrs.org/?q=pcstyle#pc_shortcuts) 导入, 然后选择其中你需要的规则.

1. ctrl + 方向键跳词
2. ctrl+A 全选
3. alt(option) + tab 切换窗口, 并支持按住 alt 后用方向键选择窗口 
	1. 我把 option 当做 alt 键用, 并交换了 option 和 command 键的位置
4. alt + 左右 前进后退
5. ctrl + ZXCVS 撤销/剪切/复制/粘贴/保存
6. ctrl +/- 浏览器缩放
7. F5 刷新

alt + tab 切窗的规则是我用 AI 写的, 写得还不错, 但是偶尔会抽风, 我不知道为什么.

---

我后来放弃了在mac 使用 windows 风格快捷键, 原因有二:
1. karabiner 并不是修改系统底层的快捷键, 原本的快捷键还是在的, 只是拦截并在对应条件下修改了键盘发送的信号, 转换成系统快捷键, 系统快捷键仍然还是存在的, 这会造成许多冲突.
2. 后来我决定以 macbook 为工作主力, 就不需要在 win 和 mac 来回切换了.

于是我卸载了 karabiner, 只是用系统自带的修饰键映射, 调整 macbook 和机械键盘的 ctrl, fn, win(command), alt(option) 为一致的相对位置.

## 状态栏

macbook 顶部的状态栏居然不能像 Windows 一样把 tray 收纳起来的功能, 测试下来发现 hidden bar 是好用又零收费零广告的解决办法, app store 就有.
