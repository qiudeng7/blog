# Work–Life Balance

我发现，我要么生活质量受到影响，要么工作质量受到影响。思考良久之后，我开始意识到，这是一个 Work–Life Balance 问题。

> 给问题像这样定性很重要。它明确了问题范围，更重要的是容易引导我联想到相关话题。

实际上，我的条件已经非常好了：有一份相对自由的工作，工作量也在合理范围内，但还是总不能兼顾工作和生活。

## 精力

我发现这样一种问题：有时候精力很好，会突然进入一种极其兴奋的状态，觉得自己什么都能做，于是制定大量计划、低估任务成本，把未来的时间提前消费。过几天，事情没有按照预期推进，精力开始下降，又进入另一种状态：觉得事情很多，什么都做不好，开始焦虑；焦虑又进一步消耗精力，导致自己更难行动。

这是一个恶性循环：高精力 → 过度规划 → 消耗过量 → 低精力 → 焦虑 → 恢复困难 → 等待下一次高精力。

最开始我认为这是自律问题，后来发现不是。如果一个系统需要依靠每天保持最佳状态才能正常运行，那么问题不在执行者，而在于系统没有得到合理设计，导致精力被无节制地消费。

理解问题之后，解决起来就很简单了：每隔一段时间，像系统中断一样停止执行，然后检查和复盘，并设计接下来的精力调度。对于我来说，只需要避免无节制地消费精力，并确保正常作息能够恢复精力即可。

## 心气

解决精力震荡之后，我发现还有另一个问题：即使睡够了，有时候依然不想工作。或者说，工作结束回家后只想打游戏，一点其他活动都不想做。这让我觉得自己的生活里只有枯燥的工作和游戏。

我觉得打游戏并不是我主动想做的，而是工作让我感到饥渴，打游戏只是一种急救。

让我们假设有一种叫作“心气”的东西。下面的心气理论并不是推理得出的，而是根据我的生活经验总结的，每个人的情况可能各有偏差。

工作在消耗精力的同时还会消耗心气。睡觉只能恢复精力，不能恢复心气。精力低迷只会让我想睡觉，但心气低迷会让我觉得活着都没有什么意思。

心气的恢复要依靠正反馈。最低级的正反馈是打游戏、喝饮料、吃烧烤、刷短视频等活动。通过这些方式恢复的心气较少，而且打一次游戏只能恢复一次心气。当心气值超过 50 时，打游戏就不会再增加更多心气。这一类正反馈就像网友所说的多巴胺或低级娱乐。

另一种正反馈来自探索新技术和消费某些优质内容，比如欣赏一部优秀的作品，或者为一个自己感兴趣的困难问题找到优雅的解法。这些事情能够恢复的心气似乎没有上限，最高可以让我的心气达到 150% 以上。它不仅能一次性恢复大量心气，还会在以后的人生中潜移默化地影响心气的平均水平，以及自己对心气变化的敏感程度。这一类正反馈就像网友常说的高级娱乐、内啡肽，或者实现自我价值带来的成就感。

这套理论可以很好地解释我面临的问题。顺着这套理论寻找解法，我毕竟不可能把一天变成 30 个小时，凭空多出几个小时补充心气，因此最好的办法还是从工作入手，尝试在工作中找到一些有意义的事情。

对我来说，2026 年以来一直在 Vibe Coding。工作本身是一件很让人厌烦的事情，生成的代码我也不愿意仔细阅读。但如果能把它当成自己的作品和心血来对待，它也可以很好地补充心气。虽然这样会让我在工作上花更多时间，但工作不会再那么痛苦，我也能从中获得一些成长。

## 从工作中提升心气

由于我是一名软件工程师，很难提出一套泛化到所有工作的理论，只能从自己的工作中总结。大致思路是：能够自动化的工作就搭建自动化；不能自动化的工作就寻找最优雅的解法；该花钱解决的问题就花钱解决。

举例来说，我每个月花 800 元通过代充购买 ChatGPT Pro 5X（即使这样仍然不太够用，准备购买 20X），每个月花六十多元购买飞书会议妙记。我给 Agent 接入了记忆系统 Mem0 和集中管理密钥的工具 Infisical，并通过 chezmoi 在多台设备之间同步 Codex 配置。

这样一来，Agent 可以帮我处理很多事情：它具备跨会话、跨设备的记忆，能够在不直接查看密钥的情况下使用密钥。开会时，我只需要打开飞书妙记，它就能整理出质量很高的会议记录，然后再让 Agent 根据会议记录安排工作。

很多琐事不再占用我的精力和心气，我便可以专心面对工作中无法自动化的部分，为它寻找优雅的解法。攻克难题之后，我的心气反而还能得到提高。
