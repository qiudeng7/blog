# uu远程的一个服务导致严重掉帧

我的很久以来电脑里都有两个系统，win10 和 win11，因为我平时使用的win11打游戏非常卡，win10有200帧，win11只有80帧，这不是win10和win11的比较，我重装新系统就会没事，之所以用 win10 而不是 win11 只是因为我想回味一下 win10 了。

我一直以为Win 11打游戏会卡是因为我的WSL和hyperv，但是有两个说不通的点，第一个是别人一般只会轻微的影响，而我的帧数却是直接腰斩；第二个是我曾经尝试在系统高级功能中关闭了 WSL 和 hyperv，帧数却仍然没有变。

今天我尝试用 windows 环境下运行 opencode，让它直接帮我查找可能的原因。 最后他发现我有两个虚拟显示适配器，其中一个被todesk和向日葵使用，还有一个叫做gameviewer, 被UU远程使用。

这个gameviewer服务，UU远程即使不启动，这个服务也会自动打开，持续的 2k144hz 录制我的屏幕占用 GPU，就像开了一个非常高画质高帧率的录屏所以很卡。

UU远程确实很好用，所以我直接卸载了todesk和向日葵，对应的虚拟显示适配器也自动删除了，而对于UU远程使用的gameviewer，可以只关闭显示适配器继续使用uu远程。

具体的操作如下：设备管理器=>显示适配器里禁用了UU远程的 `GameViewer Virtual Display Adapter`，再去win+R，`services.msc`，禁用 `GameViewerService`

然后果然win11下打游戏的帧数就只比win10低一点点了（wsl和hyperv的轻微影响）。
